# Демонстрация агентов в учебном магазине

Откройте [учебный магазин](http://127.0.0.1:4174/agent-demo.html). На каждом экране видна пометка DEMO: товары, цены, заказы и прибыль вымышлены. Реальный Ozon не меняется. Расчёт стратегий общий с рабочим магазином; отзывы проверяет настоящий локальный Qwen с резервным Codex.

1. У учебной лампы откройте стратегию. Затраты и границы уже заполнены условными данными. Выберите автоматическую работу и сохраните.
2. В верхнем блоке выберите «Достигнут рекламный порог» и примените ситуацию. В «Агентах» нажмите «Проверить сейчас». В событиях появится остановка учебной CPC-кампании с причиной. Метка результата — «Применено только в DEMO».
3. Примените «Малый остаток» и повторите проверку: агент не добавит продвижение при недостаточном запасе.
4. Примените «Проблемный отзыв». После проверки в «Отзывах» появятся ответ и краткая сводка владельцу. Генерация Qwen/Codex может занять время; состояние видно на странице. Ответ существует только в учебном магазине.
5. Примените «Нет подтверждения изменения». После проверки результат останется неизвестным и повторная отправка будет остановлена. Кнопка «Проверить результат» сверит фактическое локальное состояние учебной кампании и снимет неопределённость.
6. «Сверка прибыли» позволяет прочитать учебный отчёт и ввести условные расходы за период. Результат явно остаётся учебным. Увеличение заказов само по себе не объявляется ростом прибыли.

Каждая ситуация задаёт новые учебные условия, в том числе состояние учебной кампании. Это сценарий проверки реакции, а не прогноз рынка. Сброс доступен после завершения прогона и сохраняет предыдущий учебный снимок локально.

В рабочий магазин возвращает ссылка вверху. В нём показываются реальные API-данные и действуют реальные ограничения; недоступные методы и неизвестные затраты остаются видимыми препятствиями.

Ситуация «Опасный отзыв» добавляет учебное сообщение о задымлении и ожоге. Даже при автопилоте публичный ответ блокируется, а владелец получает срочную краткую сводку на выбранном языке. Это синтетическая проверка обработки исключений.
