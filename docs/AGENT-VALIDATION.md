# Проверка центра управления, 24 октября 2026

- Полный тестовый набор проверяет стратегии, валюты, границы цены и скидки, складской резерв, CPC/CPO, акции, отзывы, финансовую сверку, неопределённые результаты и смену правил во время исполнения. Дополнительный прогон 1200 наборов затрат и ограничений по 8 циклов проверяет сохранение ценовых и финансовых границ.
- Подключённый рабочий магазин прочитан через программу: каталог, валюта цены и доступный остаток контрольного товара проверены. Действующая стратегия остаётся наблюдением с нулевым рекламным порогом. Записей цен, остатков, рекламы, акций и публичных ответов в рамках этой разработки не было. Данные конкретного магазина в исходный код не включаются.
- Современный `/v4/posting/fbs/list` реально прочитан. Финансовое чтение контрольного товара через новый интерфейс API завершило все семь выбранных полных дней без ошибок. Суммы и подробности отчётов остаются в частном локальном хранилище. Неизвестные затраты и прибыль не выдумываются.
- Локальный Qwen 2.5 14B проверен на трёх синтетических отзывах: положительном (35,6 с), о неисправности (21,7 с) и о безопасности (21,3 с). Получены трёхъязычные сводки, опасный автоответ заблокирован. При намеренно слабом локальном результате настоящий Codex успешно завершил резервную обработку за 12,8 с. Публикаций покупателям не было.
- Недельные единицы бюджета проверялись чтением фактических кампаний и официального CSV с колонкой ₽. Записи бюджета и запуск рекламы проверены подменённым HTTP-транспортом; реальные платные запуски не выполнялись. Проверка не доказывает коммерческую эффективность.
- Дополнительная проверка настоящего Qwen на пяти синтетических пограничных случаях: вопросы о совместимости и размерах, опасная жалоба на китайском, попытка навязать обещание компенсации и обычный положительный отзыв. Все пять завершились локально за 19–30 секунд на случай; публичных отправок не было. Вопросы и опасная жалоба удержаны для владельца.
- Новый пользовательский сценарий проверен в DOM: стратегия, затраты, языки, кампании, потеря связи, устаревшие настройки из другого окна и финансовая сверка в валюте отчёта. Учебный магазин проверяется отдельно и не вызывает рабочие API магазина.
- После изменения пользователем разрешений восстановлено нативное управление Chrome. Через интерфейс пройдены выбор настоящего HTML в системном диалоге, повторный импорт по URL, просмотр карточки и источников, попытка отправки в Ozon, настройка учебных стратегий, реклама, акции, цена и опасный отзыв. Проверка через интерфейс подтвердила отсутствие фактического бренда в словаре выбранной категории; публикация не состоялась. Рабочие рекламные настройки не менялись.

Источники методов: [Seller API](https://docs.ozon.ru/api/seller/), [недельный бюджет Performance API](https://dev.ozon.ru/news/409-Performance-API-vazhnye-izmeneniia-v-rabote-API/), [отзывы](https://dev.ozon.ru/start/367-Metody-upravleniia-otzyvami-v-Seller-API). Фактическая доступность зависит от аккаунта и прав.

После фактического ответа 429 проверено ручное обновление программы: аналитика продаж, начисления, CPC и CPO завершились успешно. Отдельная квота аналитики не блокирует чтение цен и каталога. В учебном магазине опасный отзыв прошёл через работающий API программы и настоящий Qwen примерно за 39 секунд: автоматический ответ удержан, создана срочная сводка. Затем учебный магазин восстановлен в обычное наблюдение. Рабочий магазин не изменялся.

Инфографика проверяется рендером настоящих глифов: заголовки и подписи должны помещаться в свои области. Отдельная проверка сравнивает пиксели области фотографии в трёх итоговых PNG с исходным масштабированным фото. Обновление оформления хранит предыдущую версию, не меняет текст или цену и блокируется при публикации либо независимой правке черновика. Повторное чтение настоящего справочника подтвердило отсутствие SU-SIMAN в выбранной категории; подстановка другого бренда не выполнялась.

Полный повторный прогон сохранённой страницы через настоящие модели завершился состоянием `ready` за 342 секунды: извлечение через резервный Codex, проверка источников, описание на 1296 знаков, три PNG нового оформления и расчёт базовой цены ×3. Прогон использовал отдельное локальное хранилище и не отправлял товар в Ozon. Обнаруженная ошибочная блокировка числовых частей настоящего SKU исправлена: исключается только полный подтверждённый идентификатор, отдельные неподтверждённые числовые характеристики по-прежнему отклоняются. Невалидный текст Codex получает одну ограниченную попытку исправления с теми же проверками фактов.

Последний полный набор: 771 проверка без ошибок; ESLint и сборка публичного демо завершились успешно. Десятиминутная проверка работающего сервера подтвердила стабильность, сохранение режима наблюдения и отсутствие новых записей в рабочий магазин.

При проверке интерфейса исправлены сброс выбранной учебной ситуации фоновым опросом, перерисовка активного выпадающего списка, выключенная кнопка оформления после повторного импорта и пересчёта, перекрытие изображения подписью галереи, неправильная подпись расчётной маржи, дубли пояснений событий и ложная ошибка при ожидании модели. Обнаруженные состояния добавлены в проверки DOM. В Chrome отдельно проверены восстановленная кнопка оформления, сохранение выбранной ситуации после применения, остановка учебной CPC-кампании, участие в акции, изменение учебной цены и удержание опасного автоответа с краткой сводкой владельцу через настоящий резервный Codex.

Дополнительно через работающий сервис обработана новая сохранённая страница массажной маски: выбранный цвет и стандартный вариант сохранены, создано 1386 знаков описания и три PNG. Проверка изображений выявила шаблон совместимости, не подходящий самостоятельному товару; добавлен отдельный вариант оформления назначения. Обновление изображения выполнено через действие redesign с сохранением предыдущего варианта. Цена до скидки явно помечается оценкой закупки. Известные китайские и латинские написания Mijia сопоставляются отдельно от Xiaomi; чужой бренд и неоднозначные ID не принимаются. Полный набор после изменений: 773 проверки без ошибок, ESLint пройден.

Попытка отправки новой маски через API сервиса прошла сопоставление бренда, но остановилась до импорта из-за отсутствующих подтверждённых полей «Производитель» и «Страна-изготовитель». В исходном HTML этих полей нет; сведения о похожем товаре не подставлены. Карточка остаётся локальным готовым результатом, без покупательской ссылки Ozon.
