# AIGC 创意闭环 / Генеративный сценарий

Главный сценарий демонстрации: **отзыв → проблема в содержании карточки → подтверждённые факты → русские текст и инфографика → сравнение → подтверждение продавца**. Экономика SKU — следующий этап проверки эффекта контента, цены и рекламы.

Согласно [странице конкурса](https://www.synnovator.com/hackathon/hfhahkjfdhakfhf), трек включает продуктовые материалы, визуальные решения и анализ трафика. Поэтому аналитика уместна, но для нашего трека AI产品资料子赛道 генеративный результат должен быть виден сразу. Заявление о несовместимости BI с конкурсом не доказано; недостаточная заметность AIGC — практический риск презентации.

## Что реализовано

- `AIGC 图文改进` в китайском рабочем интерфейсе: выбранный отзыв, SKU, подтверждённые факты, исходная картинка и её текст.
- Настоящий вызов подписки Codex для анализа возражения, русской подписи, китайского объяснения и инструкции редактирования изображения. Параметры и результат хешируются, работа фиксируется до вызова. После перезапуска нет автоматического повторного вызова.
- Загрузка результата внешнего генератора, сравнение исходного и нового изображения, проверка фактов, внешнего вида, русского текста и прав. Источник внешнего изображения — заявление продавца, не подтверждённый API-чек.
- Подтверждение точного хеша. Замена изображения создаёт следующую версию, сохраняет предыдущую и сбрасывает подтверждение. Изменение исходного отзыва блокирует дальнейшее подтверждение. Недостаток фактов не позволяет подтвердить; проблемы качества/сервиса требуют отдельного признания ограничения.
- Никаких записей в маркетплейс из этого модуля. Связка одобренного креатива с планом тестирования и существующей карточкой ещё не реализована.

## xds.studio

13.10.2026 на публичной странице конкурса подтверждено упоминание студии и её генеративных моделей. Получить документацию API xds.studio не удалось; это не доказывает отсутствие API. Нативная интеграция не заявляется. Сейчас продавец переносит инструкцию и исходную картинку в студию вручную и загружает результат в рабочее пространство. Нужен проверенный официальный контракт/доступ для автоматизации этой стадии.

## Демо на китайском

`web/demo-zh.html` — отдельное публичное демо с `lang="zh-CN"`: китайские кнопки, объяснения и гейты; русский только внутри материалов для покупателя. GitHub Pages публикует его как главную страницу через явный список публичных файлов в `scripts/build-public-demo.mjs`. Приватный API-интерфейс и runtime в этот пакет не входят.

Сценарий на 3 минуты:

1. Показать синтетический отзыв «На фото не понял размеры» и китайское понимание.
2. Открыть предложение: уточнить размеры, не обещая улучшить качество товара.
3. Сравнить две настоящие генерации OpenAI: исходник без размеров и отредактированную картинку с 40 × 30 × 25 см.
4. Отметить проверки и подтвердить демонстрационную версию. Страница явно сообщает, что подтверждение не публикует товар.
5. Показать границы: xds.studio вручную, живой текстовый вызов в локальном приложении, реальные магазинные испытания ещё впереди.

Публичный сценарий воспроизводит заранее подготовленные результаты, а не изображает онлайн-генерацию. Источник, время проверки текстового адаптера и хеши PNG сохранены в `AIGC-DEMO-EVIDENCE.json`. Это не замер на реальном товаре и не доказательство снижения возвратов или роста прибыли.

## Оценка входа на площадки

Дополнительно упрощена оценка магазина: одна обычная форма SKU вместо обязательного JSON. Ozon основной, отдельные предположения WB раскрываются по необходимости; пакетный JSON остаётся отдельным режимом. Новые оценки принимают проверенные RUB-суммы без встроенного FX. Исторические расчёты не изменяются, неизвестные затраты не становятся нулевыми.
