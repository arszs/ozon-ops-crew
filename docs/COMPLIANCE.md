# 安全与实现边界 · 2026-10-23

本页说明当前技术行为，不构成已完成的法律合规认证。

## 数据与外部处理

- 完整工作台在本机 loopback 运行，状态、上传文件和日志由本地服务端持久化；不是“所有数据仅在浏览器 localStorage”。公开演示仅打包明确列出的合成示例资产。
- Codex 文本转换会将提供的商品/评价事实发送至相应服务处理。手动图像生成也会把选定素材发送至用户选择的外部工具。需要确认素材使用权及允许处理/展示的范围；不要向模型发送平台密钥或买家身份信息。
- 本版交付仅取 Git 跟踪的项目文件；不包含本机 runtime、私有财务、账号配置、上传素材或凭据。历史生成证据对应合成输入。
- 生产认证、多租户隔离、KMS、分布式后台等仍未实现；不能把未来设计描述为已部署保护，也不宣称已经完成跨境数据法律评估。

## 平台与内容

- 已实现 Ozon 读取以及价格/CPO 的准备、确认、执行和回读适配；真实账号权限与有效性需要单独验证，代码存在不等于真实写入成功。
- 每个写操作绑定账号、SKU、来源版本和确切参数，需独立确认与明确执行。未知结果先核对，不盲目重试；取消计划不恢复平台状态。
- 预算与亏损阈值不是平台自动止损保证。当前准备不修改价格、广告或促销设置。
- AI 输出是草稿；核对事实、外观、俄语及图片权利后确认。不能编造认证、尺寸或质量改善，不能用图文掩盖实物/服务问题。版本审核不等于发布或通过平台审核。
- 示例金额为合成假设；无真实节省时间、退货下降或利润增长结论。
