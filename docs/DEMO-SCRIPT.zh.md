## 0:40–2:20 · AIGC 可以改什么

打开 https://arszs.github.io/ozon-ops-crew/ ，或用本版 `npm run demo:build` → `npm run demo:serve` 打开 http://127.0.0.1:4174/ 。明确指出“中文交互演示 · 合成商品”。

选择“查看 AI 改进方案” → “对比生成图片”。俄语买家说图片尺寸不清；已确认的示例尺寸是 40 × 30 × 25 cm。展示真实生成的前后图片：补充尺寸，不虚构质量改进。

展开“在雪窦山 Studio 试做这张图”，展示可下载的原图、中文指令和手动步骤；不要把已有 OpenAI 图片说成 Studio 生成结果。

逐项核对事实、外观、俄语和图片使用权，确认演示版本。说明：这一步不会发布到 Ozon。示例图片来自 OpenAI；xds.studio 目前支持手动工作流，原生 API 尚未验证。

## 2:20–3:30 · 多卖不一定多赚

进入第四步“经营验证”。先不勾核对项计算，页面应提示信息不足。

按演示假设勾选两项，计算日均贡献差额。将测试期成本改成 48,000 ₽，重新核对后计算：订单从 40 增到 44，但日均贡献下降约 405.71 ₽。清空一个成本，页面应要求补齐，不能当作零。

所有金额都是可编辑的合成假设。这验证计算与交互，不证明新图增加了真实利润。

## 3:30–4:50 · 本地 AIGC 链路与可选经营验证

打开 [ARCHITECTURE](ARCHITECTURE.md)，解释：来源/事实校验 → Codex 结构化文案 → 外部生成图片 → 上传 → 人工审核 → 冻结版本。若有经授权的本地连接，可展示同商品的记录、来源哈希和版本；没有真实案例时只展示合成记录，不冒充真实效果。

打开 [CONTENT-PILOT](CONTENT-PILOT.md)，说明同输入的人工/辅助内容制作对照：活跃时间、总耗时、纠错及审核质量。真实卖家尚未测量，十个准备好的 SKU 不等于十个完成的案例。
