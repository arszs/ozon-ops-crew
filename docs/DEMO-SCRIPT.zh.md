# 三分钟演示稿

**0:00–0:25 · 问题**
中国跨境卖家不能只看销售额。仓储、广告、汇率和补货周期决定这笔订单到底赚不赚钱。Ozon Ops Crew 把这些因素放进同一个经营控制台。

**0:25–1:00 · 亏损保护**
打开第一件商品。广告前利润为正，但最近三笔交易分摊广告后合计亏损。超过配置上限时，系统给出暂停广告并冻结价格的建议，记录依据。当前是模拟操作，尚未修改真实广告。

**1:00–1:40 · 库存决策**
选择季节商品。低仓储成本时可以等待旺季；提高仓储成本再计算，策略会改变。再查看补货要21天、库存仅够4天的商品，系统建议保护库存而非盲目加广告。

**1:40–2:10 · 商家控制**
进入风控设置，展示店铺默认规则与 SKU 覆盖。调整亏损窗口、广告限额和价格上限。所有建议可解释，模拟动作可追溯。

**2:10–2:35 · 真实连接**
只在本地私密演示时展示 Seller API 目录读取；公开演示不用真实商品数据。采购数据由 Excel 导出 CSV 导入。广告写入尚未接入。

**2:35–3:00 · 验证路径**
今天展示的是工作原型，不宣称已经提升真实利润。下一步用结算数据校准，在影子模式验证，再进行受限对照试点，以广告后利润和库存成本衡量效果。
