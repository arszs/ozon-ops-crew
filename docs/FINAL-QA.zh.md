# 决赛问答 · 当前版本 2026-10-23

## 解决什么问题？
为缺少俄语团队的中国卖家，把买家评价中的表达问题变成可审核的俄语商品图文。真实目标卖家访谈和用时测量尚未完成，这是待验证的用户假设。

## Agent 具体做什么？
有限文本转换生成俄语文案、中文解释及图像编辑指令；代码做来源、结构、版本及状态校验，卖家完成图片生成和最终审核。不是六个自主大模型的生产集群。[ARCHITECTURE](ARCHITECTURE.md) 给出代码对应关系。

## xds.studio 接通了吗？
当前是原图/指令导出→在 Studio 手动生成→上传审核；未验证原生 API。公开样例图片由 OpenAI 工具生成，不能说成 Studio 的生成结果。

## 图片是现场生成的吗？
公开页回放真实生成的预制图片，商品/评价/金额是合成的，不连接店铺。完整本地工作台可以调用已登录的 Codex CLI 生成文本；图片需要外部生成再上传。

## 节省多少时间、增加多少利润？
尚无完成的真实用户配对测量，不报告节省比例或利润提升。当前用同一输入对比手工与辅助制作，记录活跃时间、总耗时、纠错与审核质量。[CONTENT-PILOT](CONTENT-PILOT.md)。模型调用耗时、历史价值模型和测试数量都不替代用户效益。

## 为什么不只用图像工具或 ERP？
本项目尝试连接评价、核实事实、俄语内容、版本审核及后续同 SKU 验证。与手工/ERP/其他图像工具的同输入实测尚未完成，不宣称优于 Miaoshou。

## 会自动改价或止损吗？
价格/CPO 有单独的准备、确认、明确执行及回读流程。完整真实写入和收益链条尚未证明；预算与亏损阈值不保证自动停止平台开支。当前内容演示不修改平台。

## 数据在哪里？
完整工作台的数据在本地服务端；公开页仅含允许打包的合成资产。文本调用和用户选定的图像工具涉及外部处理，需要素材授权。不是“所有数据只在浏览器且不离开电脑”。

## 测试与生产准备？
本次测试数量、时间和版本见 [RELEASE-VERIFICATION.json](RELEASE-VERIFICATION.json)。自动测试主要验证代码与合成场景；真实账号效果需独立证据。生产身份认证、多租户隔离及分布式任务未完成。

## 网络故障怎么办？
用交付包：`npm run demo:build` → `npm run demo:serve` → http://127.0.0.1:4174/ 。不需要店铺连接或在线生成。旧 demo.mp4 是历史模拟器，不用它代表当前产品。
