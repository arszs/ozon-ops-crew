# 已保存商品页导入与定价

商品迁移页现在可以接收浏览器保存的 Taobao / Tmall HTML，不需要手写商品 JSON。
该流程不读取浏览器登录资料，不执行页面脚本，也不会绕过访问限制。

## 本机运行

```sh
npm ci
ollama list
# 如本机未安装所需模型，再由用户安装。程序不会自动下载模型。
export OPS_QWEN_MODEL=qwen2.5:14b
export OPS_PAGE_FALLBACK=codex
npm start
```

在「商品迁移」中选择店铺，上传保存的 `.html`。如果 HTML 没有保存原链接，
补充原商品链接。源链接中的追踪参数会被移除，保留商品 id 和 skuId。
Ollama 只使用本机 `127.0.0.1:11434`，不接收 Ozon 密钥。

也可以使用同一后端的命令行：

```sh
node scripts/import-page.mjs /absolute/saved.html \
  --source-url 'https://item.taobao.com/item.htm?id=123&skuId=456' \
  --store ozon-live
```

使用 `--store` 时先启动本机服务；可用 `--port 4174` 指定本机端口。任务通过 HTTP 交给服务保存，CLI 不直接并发修改工作台数据库。省略 `--store` 只保存提取结果，不创建工作台任务。结果位于被 Git 忽略的
`runtime/page-import/`：`report.json`、`product.json`、`review-packet.json`。
这些文件包含商品和经营信息，不应提交到公开仓库。

## 模型与证据

1. HTML 解析器提取商品正文、已选规格、可见价格及原图 URL。
2. 本地 Qwen 生成带原文证据的结构化商品数据与保守俄语草稿。
3. 程序检查价格、规格、属性证据、标题和俄语中的数字。自报置信度不作为放行依据。
4. 弱结果通过已有的 Codex 订阅 CLI 重新处理。CLI 工具调用被禁用，
   只传递清理后的商品证据，不传递完整 HTML、卖家密钥或浏览器账户资料。
5. 若仍失败，结果停在 `needs_review`。界面可下载核对包交给 Codex，
   不会把弱结果创建成可发布商品。

`OPS_PAGE_FALLBACK=review` 或 CLI 的 `--fallback review` 可关闭自动 Codex
请求，只保留核对包。本机 Qwen 可用但不保证每次结果足够好。

检查是结构和原文依据的检查，不能独立证明商品真实性、兼容性、图片权利或认证。
当前解析器优先适配 Taobao 桌面保存页的 mainTitle、highlightPrice 和已选规格结构。
页面缺失、版本不同、多价格或多规格不明确时停止并要求检查。页面不会直接在界面渲染。

图片只从允许的公开 CDN 下载，拒绝重定向与私网地址。真实尺寸来自图片文件。
程序不会推断图片使用权，不会自动清除第三方水印。现有图片、类目与发布确认继续生效。

## 让卖家保留源商品价格

类目与发布资料区域增加净回款定价表单。目标净回款默认等于源商品价格。
支持 CNY 等店铺币种；同币种不进行虚构汇率换算，跨币种必须明确输入汇率。

售价 =（目标净回款 + 固定费用）÷（1 − 销售额比例费用 − 售价内增值税比例）

售价内增值税比例为 `vat / (1 + vat)`，随后向上取整至货币最小单位。
固定费用包括所填全程物流、包装、关税、不可抵扣进口税、文件等。
比例费用必须使用已核定的有效销售额比例。程序不会从其他 SKU 推断佣金，
不会自行选择税制，也不会把淘宝国内运费当成跨境运费。抵扣税额和利润税
需要先换算为适用的成本参数，不能直接套用名义税率。

后端 `landedPrice()` 还支持体积重报价：使用包装尺寸、实际重量、承运商体积系数、
计费重量步长、基础费、每公斤费及最低收费。该规则是可配置承运商报价，
不是声称已接入 Ozon 全部动态计费规则。

没有确认成本或必填值为空时不输出可用售价；明确的零费用由用户填写。
保存新价格会撤销旧发布确认。计算完成仍不等于发布、审核通过或开售。

## 界面与真实连接

「店铺管理」可输入 Client ID 和 API key，或选择已有 `.env` 文件。
服务端先调用 Ozon 的只读商品列表接口验证连接，再将密钥保存到本机用户配置目录，
权限为 0600。浏览器响应、操作证据和 Git 仓库不包含密钥。

迁移页使用三个步骤：上传商品页、核对商品与价格、提交 Ozon。
JSON 导入、测试商品、历史任务与运行证据默认折叠；任务链接支持刷新后继续。
包装尺寸在界面使用厘米，提交 Ozon 时转换为毫米。可先保存不完整草稿，
实际提交仍要求价格、包装、图片、字典属性及必要确认全部齐全。

可选择「使用这些原图」保留来源照片，不强制翻译或重绘。
此操作不会删除水印，也不会宣称做过 OCR 或生成俄语图片。
使用原图时自动填入原始公开图片地址；处理后的图片仍需配置公开存储。
来源图片许可与发布前商品权利、认证核对是不同事项，程序不会自动代填。


## OGL 一键估价

已保存明确的包装与零税率后，可点击「按 OGL 自动计算售价」，无需反复输入运费。
程序按 2026-08-24 官方 OGL 表枚举六个价格/重量组，重件组使用实际重与体积重较大值。
计算同时反推售价、销售佣金档位与 OGL 服务费，避免加上运费后跨档却仍使用旧档。
人民币换算按俄罗斯央行当天查询的有效汇率，服务费按售价 2%、每件 15–200 RUB 范围估算。
自动销售佣金目前仅覆盖摩托车刹车灯类型 971168876，使用官方中国 realFBS 类型行，
OGL 实际结算佣金仍以店铺账单为准，不将不同履约方案说成已核实相同。

中国境内运费读取保存页展示的快递金额；这条展示路线未必是实际 OGL 入仓路线。
包装 2 CNY 与其他费用预留 2% 是可修改估计，不是 Ozon 官方收费，也不保证覆盖
所有支付、退货、促销或汇兑成本。详情显示依据、版本和假设，不弹出额外确认问题。
商品已有的权利与文件确认随草稿保存；最终卡片提交合并为一个明确按钮，
后端仍依次校验版本、生成计划、记录确认，并在核对货号未存在后仅创建新卡片。
不设置库存，不预约揽收，不自动改变店铺的配送方式。
