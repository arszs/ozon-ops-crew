Название заявки: **Ozon Ops Crew — 评价驱动的 AIGC 商品图文与单品利润验证**.

Фокус: китайский продавец, отзыв → проверенные факты → русская инфографика → подтверждение версии; экономика SKU и эксперименты проверяют эффект. Amazon / Shopify / Wildberries / TikTok Shop обозначены будущими API-адаптерами; существующий WB-код описан как предварительная интеграция без проверки реальным аккаунтом. Закупки, ввоз и конвертация закупочной валюты исключены из позиционирования.

Реализация, синтетические проверки, будущие возможности и целевые метрики разделены. Публичное GitHub Pages демо — китайский интерактивный сценарий с настоящими предварительно сгенерированными изображениями OpenAI и синтетическим товаром. Это не онлайн-генерация и не подключённый магазин. xds.studio обозначен ручным этапом, API не проверен. Рабочий интерфейс требует локального сервера. Ссылки на proposal/evaluation в main выше — исторические материалы; текущие возможности см. в ветке разработки и сохранённом описании у организатора.
