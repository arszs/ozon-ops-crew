# Ozon Ops Crew — AIGC 商品表达与单品利润决策

参赛方向：品牌出海场景 / **AI产品资料子赛道**。材料整理：2026-10-23。当前是可演示原型，真实用户效益尚未测量。

## 1. 用户与创作问题

面向缺少俄语团队的中国卖家，以俄罗斯 Ozon 为首个验证场景。俄语评价可能暴露尺寸、用法等信息不清的问题；卖家需要把已核实事实变成买家能看懂的俄语图文。目标用户与痛点仍需真实卖家访谈确认，不把假设写成调研结论。

## 2. 主场景与交付物

评价 → 核对商品及事实 → 生成俄语标题、文案和中文绘图指令 → 在外部图像工具生成并上传 → 对比原图/新图 → 核对事实、外观、俄语与使用权 → 确认版本。

输出包含俄语内容、中文解释与图像指令、原图/新图、来源和版本哈希及审核记录。质量或服务问题单独处理，不能用新图掩盖；缺失事实不能凭空补写。确认不等于平台发布。

本地工作台通过已登录的 Codex CLI 生成结构化文本；图像由外部工具生成后上传。xds.studio 当前为手动流程，原生 API 未验证。公开样例图由 OpenAI 工具生成，不冒充 Studio 结果。

## 3. Agent 方案

输入与来源检查 → 有限文本生成 → 结构校验 → 等待外部图片 → 人工审核 → 冻结版本 → 可选的同 SKU 经营实验。持久化状态、来源哈希、版本检查及工具日志用于追溯；改图会使旧审核失效。阶段代表明确的软件职责，不等于六个自主大模型协同。

[架构与代码入口](ARCHITECTURE.md) · [接口与人机边界](SPECS.md)。经济计算使用确定性代码；价格/CPO 的准备、确认、执行与回读分别处理。预算/亏损阈值不是保证自动停止平台支出的限额。

## 4. 可运行演示

[公开演示](https://arszs.github.io/ozon-ops-crew/)：中文交互、合成商品与评价、真实生成的预制图片。依次查看方案、对比图片、核对版本、比较两期贡献。成本提高时订单增加也可导致利润下降。页面不连接店铺、不在线生成、不发布、不投放广告。

本版离线包：仓库根目录运行 `npm run demo:build`、`npm run demo:serve`，打开 http://127.0.0.1:4174/ 。完整工作台需 Node >=22.13、`npm ci`、`npm test`、`npm start`，打开 http://127.0.0.1:4173/ 。真实连接与 Codex 登录单独配置。

## 5. 证据与实际效益

已经存在真实 Ozon 读取记录、结构化文本调用记录、图片哈希与合成测试。历史账户读取有覆盖与权限缺口；详见 [EVALUATION](EVALUATION.md)，本次整理没有刷新账户数据。

**未完成真实卖家的人工/辅助配对测量；未证明节省时间、降低退货或增加利润。** 已准备的十个 SKU 不是十个已完成案例。优先用同一商品输入比较手工与辅助制作图文的活跃时间、总耗时、纠错与审核质量，保留失败和负向结果。[内容试点协议](CONTENT-PILOT.md)。

已审核图文可关联同店同 SKU 的经营实验，但实际发布及平台展示需另行核对。利润验证要完成可比期间、全部成本和退款/广告核对；顺序比较不能直接证明因果。真实价格或广告修改不是展示内容制作效率的前提。

## 6. 评分对应

| 评审项 | 权重 | 本版证据与边界 |
|---|---:|---|
| 业务需求 | 15% | 中国卖家→俄罗斯市场→商品表达问题；真实访谈待补 |
| Agent 方案 | 25% | 来源/结构校验、有限生成、状态持久化、人工审核、版本及工具日志 |
| Demo | 20% | 可运行中文合成示例、本地工作台、当前演示稿；非在线店铺闭环 |
| 实际效益 | 25% | 已备配对测量表与协议；尚无真实测量结果 |
| 创新与扩展 | 10% | 评价驱动图文审核与同 SKU 经营验证；尚无同输入竞品测量 |
| 安全 | 5% | 服务端密钥、外部生成标识、版本审核、有限公开资产；非生产多租户系统 |

## 7. 范围

Ozon 为主要验证场景；WB 是未经真实账户验证的预研。Taobao 使用结构化输入，不声称已接通账号。采购、进口、采购币种兑换不属于主场景。身份认证、多租户隔离与分布式后台未完成。
