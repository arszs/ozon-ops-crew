# Full Taobao gallery and Ozon rich content

Studio inventories original product gallery images and `descV6-mobile-image` blocks, keeping source order and excluding customer reviews and unrelated page graphics. It no longer makes three slides from one photo. New imports localize the complete source when all original files are reachable. If a saved HTML references companion files, upload its `_files` folder in the product's “All Taobao photos and rich content” panel and start localization there.

Each retained source image has OCR/translation, selected-variant checks, source asset IDs and a visual review. Consecutive long-description slices can form one layout. Revision-specific specifications, unrelated seller banners and service graphics remain in the source archive with exclusion reasons. Product and lifestyle photography is preserved; failed localization receives one bounded correction attempt. Completed images are cached and resumed after interruption.

The image editor uses the authenticated Codex CLI built-in `image_generation` feature, with shell, connectors, browser and other tools disabled in that subprocess. It does not require a separate image API key. The local Qwen/content fallback remains available for product copy. Photo-overview video needs `ffmpeg` and `ffprobe` on PATH. A photo overview is labelled as such; it is not represented as footage of a product test.

Before creating an Ozon card, prepared rich media is attached to the publication flow automatically after the base product is confirmed. Existing cards use the “Update Ozon” action and retain the same offer, price and stock. The service checks for owner edits and preserves previous content and receipts. Unknown write outcomes cannot be resent automatically; explicit API invalid-argument rejections retain their safe diagnostic and can be corrected.

Rich JSON is validated against the official Ozon schema, vendored in `core/ozon-rich-schema.json` from <https://cdn2.ozone.ru/s3/artifact/schema.json> (retrieved 2026-10-24). Publication verification accepts Ozon's CDN URL rewriting while checking the remaining rich structure and text. The actual score is read from `/v1/product/rating-by-sku`; no locally estimated score is displayed as an Ozon result. Scores and moderation can lag behind accepted import receipts. Optional attributes are filled only when supported by product evidence and the current category dictionary.

Live verification on 2026-10-24: the Mijia eye-mask listing's score increased from 33.5 to 100, with 12 gallery images, 11 translated rich sections and a 20-second photo overview. Of 32 source images, 25 product images were localized into 16 layouts and 7 unrelated/unconfirmed sections were archived. This is one verified listing, not a guarantee of a 100 score for every category. Its price stayed 1137.63 CNY and no stock was added.
