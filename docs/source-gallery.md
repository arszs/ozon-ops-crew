# Full Taobao gallery and Ozon rich content

Studio inventories original product gallery images and `descV6-mobile-image` blocks, keeping source order and excluding customer reviews and unrelated page graphics. It no longer makes three slides from one photo. New imports localize the complete source when all original files are reachable. If a saved HTML references companion files, select both the HTML and its `_files` folder in the initial Studio form. Only image files are uploaded; the service validates and saves the file manifest alongside the source. The same folder can be attached later in the product’s “All Taobao photos and rich content” panel. Missing source images and unfinished/failed full-gallery localization block publication instead of silently sending a partial card.

Each retained source image has OCR/translation, selected-variant checks, source asset IDs and a visual review. Consecutive long-description slices can form one layout. Revision-specific specifications, unrelated seller banners and service graphics remain in the source archive with exclusion reasons. Product and lifestyle photography is preserved; failed localization receives one bounded correction attempt. Completed images are cached and resumed after interruption. A visual-stage retry reuses the same unchanged source job and approved copy, rather than rerunning extraction and rewriting the description. Temporary model timeouts receive one bounded retry; excluded seller banners do not require a product caption. Both Taobao V6 and V8 long-description layouts are inventoried.

The image editor uses the authenticated Codex CLI built-in `image_generation` feature, with shell, connectors, browser and other tools disabled in that subprocess. It does not require a separate image API key. The local Qwen/content fallback remains available for product copy. Photo-overview video needs `ffmpeg` and `ffprobe` on PATH. A photo overview is labelled as such; it is not represented as footage of a product test.

Before creating an Ozon card, prepared rich media is attached to the publication flow automatically after the base product is confirmed. Existing cards use the “Update Ozon” action and retain the same offer, price and stock. Pending Ozon processing and prepared rich-media follow-up continue in a server worker, even if the browser tab is closed. Failed rich follow-up is held with its diagnostic instead of repeatedly submitting it. The service checks for owner edits and preserves previous content and receipts. Unknown write outcomes cannot be resent automatically; explicit API invalid-argument rejections retain their safe diagnostic and can be corrected.

Rich JSON is validated against the official Ozon schema, vendored in `core/ozon-rich-schema.json` from <https://cdn2.ozone.ru/s3/artifact/schema.json> (retrieved 2026-10-24). Publication verification accepts Ozon's CDN URL rewriting while checking the remaining rich structure and text. The actual score is read from `/v1/product/rating-by-sku`; no locally estimated score is displayed as an Ozon result. Scores and moderation can lag behind accepted import receipts. Optional attributes are selected from the live category schema and filled only with exact source evidence and unique matching dictionary values. Existing owner attributes are preserved; identity changes or concurrent remote attribute edits stop the update.

Live verification on 2026-10-24: the Mijia eye-mask listing's score increased from 33.5 to 100, with 12 gallery images, 11 translated rich sections and a 20-second photo overview. Of 32 source images, 25 product images were localized into 16 layouts and 7 unrelated/unconfirmed sections were archived. This is one verified listing, not a guarantee of a 100 score for every category. Its price stayed 1137.63 CNY and no stock was added.

An unrecognized composite seller-brand field can be reconciled only when the same actual product brand appears in the source title and retained product-gallery OCR. The replacement still requires an unambiguous live Ozon dictionary match. This path cannot replace a missing single accessory brand with the compatible-device brand. Source quote and image identity remain attached to the result.


Selected revision tables can contribute specifications when their printed product name explicitly matches the chosen revision and an independent vision check confirms product type and identity against the selected source photograph. Generic/unselected revision tables remain archived. Centimetre fields support evidence-bound millimetre conversion; colour observations retain separate selected-photo provenance. Recommended category dictionaries are supplied to the attribute transformer, and equivalent dictionary choices must reference real returned IDs. Country/manufacturer are never inferred from a brand or retailer location.

Media preparation has a persisted atomic lock and visible upload/copy/attribute phases. Restart releases pre-send preparation while keeping uncertain post-send outcomes blocked. Current attributes are compared independent of their order: live Ozon reads were observed swapping video URL/title rows. Actual owner values are still protected. Unchanged source OCR and approved copy reuse the initial workflow cache. Public asset reuse verifies Git blob identity rather than downloading the same large file again. Buyer preview links include `oos_search=false` so an unavailable offer can be inspected without adding stock.

Additional live UI verification on 2026-10-24: Mijia 1S soap-dispenser bundle, Taobao item 632780333053 / selected SKU 4692848743080, buyer SKU 6130020711. The actual Studio HTML + companion-folder upload contained 47 image files; 24 product-source images were inventoried, 22 became 14 localized layouts and 2 unrelated/unconfirmed images remained archived. Ozon accepted 12 gallery images, 8 rich sections and the photo overview. Source-backed automatic attributes raised the actual score from 77.5 to 100/100; all three rating groups are maxed. Price stayed 350.67 CNY (116.89 landed estimate ×3), and stock was not changed. Country of manufacture was not invented to achieve the score. This walkthrough included program fixes, followed by UI retries; it is not evidence that an arbitrary new Taobao URL can always reach 100 without a saved source, sufficient facts, or moderation.
