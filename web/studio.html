ВАШЕ ДЕМО ЗА НЕСКОЛЬКО МИНУТ

Ссылка → красивая карточка → Ozon

  1. Вставьте URL Taobao со выбранным вариантом. Если сайт просит войти, сохраните страницу через ⌘S и загрузите HTML сюда. Фотографии сервис загрузит сам.
  2. Нажмите «Создать карточку». Qwen извлечёт факты, Codex подхватит сложные шаги, найдёт источники и подготовит описание и оформление. Можно закрыть вкладку — процесс продолжается.
  3. Посмотрите результат. Проверьте выбранный вариант, фотографии и упаковку. Цена уже равна рассчитанному базовому значению × 3; налог — 0, комиссия и упаковка помечены как оценки.
  4. Нажмите «Отправить в Ozon». Это одна команда на публикацию показанного варианта. Затем откройте карточку по ссылке покупателя. Остаток автоматически не добавляется.

На Taobao могут потребоваться вход и HTML. Модерация Ozon и обновление витрины происходят на стороне Ozon. Повторный запуск уже загруженного URL использует сохранённую страницу — это видно в источнике.
